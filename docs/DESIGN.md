# ScopePay design specification

Reference: `concept.png`, generated with the built-in Image Gen tool. Prompt: a complete ScopePay desktop product workspace with a 220px sidebar, brief form, three-milestone preview and connection strip; white, navy and cobalt, readable Inter typography, no photos or decorative metrics.

Tokens: white background; #0b1538 text; #62708c muted text; #0066ff action; #dbe2ee border; #edf6ff preview; 12px panel radius; 8px controls; 16/24/32px spacing. Inter: 40px headline, 24px panel heading, 15px body, 13px captions. Outline Lucide icons at 20px and typographic S brand mark. Sidebar 238px, content padding 32px, two equal panels. On narrow screens use compact horizontal navigation and stacked panels.

Inventory: Workspace / New proposal breadcrumb, Sandbox mode, primary heading and subtitle, Brief / Review scope / Collect payment steps, brief form, example preview and connections strip. Review, saved projects, connection dialog and payment screens extend the same token system to make the required workflow functional.

Intentional copy deviations: replace the generated concept's inaccurate escrow/release implication with direct milestone payment language. No escrow or automatic release. Show actual integration status rather than always showing Setup required. Model output replaces sample preview only after successful generation. Reference milestones are explicitly labeled as examples. Connection status describes local brief processing; PayPal necessarily receives payment details.
